# Deepfake Dashboard Auth (React + Tailwind)

pip install -r requirements.txt --upgrade

## Run
1) Install deps
```bash
npm install
```

2) Start dev server
```bash
npm run dev
```
3) Start the Server
```bash
python -m uvicorn main:app --reload --port 8000
```
Open the URL shown in your terminal (usually http://localhost:5173)

## Routes
- /signin
- /signup
